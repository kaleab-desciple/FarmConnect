## 1. Executive Summary

This document provides a simplified blueprint for implementing a production-ready AgriManagement System using:
- **FastAPI** microservices with async I/O
- **Dual persistence**: PostgreSQL/PostGIS + MongoDB
- **Kubernetes** with HPA for seasonal scaling
- **Manual data entry** for soil and environmental readings (no IoT edge devices)

**Key Change**: All real-time IoT sensor functionality has been removed. Soil readings, weather data, and irrigation scheduling are now based on manual entry, satellite imagery, and third-party weather APIs.

## 3. Domain-Driven Design & Bounded Contexts

### 3.1 Field Management Context
- **Responsibility**: Farm boundaries, crop planning, GIS operations
- **Database**: PostgreSQL + PostGIS
- **Key Entities**: Farm, Field, CropCycle, SoilProfile

### 3.2 Manual Data Entry Context (Replaces IoT)
- **Responsibility**: Manual soil readings, weather observations, irrigation logging
- **Database**: PostgreSQL
- **Key Entities**: SoilReading (manual), WeatherObservation, IrrigationEvent, FieldVisitLog

### 3.3 AI & Diagnosis Context
- **Responsibility**: Pest/disease identification, image analysis, ML model management
- **Database**: MongoDB
- **Key Entities**: Diagnosis, ImageMetadata, MLModel(not for now), TreatmentRecommendation

### 3.4 Advisory & Collaboration Context
- **Responsibility**: Expert forums, chat, knowledge base
- **Database**: MongoDB
- **Key Entities**: ForumThread, Message, ExpertProfile, KnowledgeArticle

### 3.5 Weather & Risk Context
- **Responsibility**: Third-party weather APIs, risk alerts, manual observations
- **External APIs**
- **Cache**: Redis

### 3.6 Analytics Context
- **Responsibility**: NDVI analysis, yield prediction, manual data trends
- **Database**: PostgreSQL (materialized views)
- **Key Entities**: NDVITile, YieldReport, SoilTrendAnalysis

# manual_data_service/main.py
from fastapi import FastAPI, Depends, HTTPException
from sqlalchemy.ext.asyncio import AsyncSession
from pydantic import BaseModel
from datetime import datetime, date
from typing import Optional, List
import aiokafka
import json

app = FastAPI(title="Manual Data Entry Service")

# Database dependency
async def get_db():
    async with async_session() as session:
        yield session

# Pydantic models
class ManualSoilReadingCreate(BaseModel):
    field_id: str
    moisture_percent: Optional[float] = None
    temperature_celsius: Optional[float] = None
    ph_level: Optional[float] = None
    nitrogen_mg_kg: Optional[int] = None
    phosphorus_mg_kg: Optional[int] = None
    potassium_mg_kg: Optional[int] = None
    notes: Optional[str] = None
    gps_latitude: Optional[float] = None
    gps_longitude: Optional[float] = None
    weather_conditions: Optional[str] = None

class IrrigationScheduleCreate(BaseModel):
    field_id: str
    scheduled_date: datetime
    duration_minutes: int
    water_volume_liters: float
    notes: Optional[str] = None

# Endpoints
@app.post("/soil-readings", response_model=dict)
async def create_soil_reading(
    reading: ManualSoilReadingCreate,
    db: AsyncSession = Depends(get_db),
    current_user: User = Depends(get_current_user)
):
    """
    Record manual soil reading from field visit
    """
    query = """
    INSERT INTO manual_soil_readings 
    (field_id, recorded_by, moisture_percent, temperature_celsius, ph_level,
     nitrogen_mg_kg, phosphorus_mg_kg, potassium_mg_kg, notes, 
     gps_location, weather_conditions)
    VALUES 
    (:field_id, :user_id, :moisture, :temp, :ph, :n, :p, :k, :notes,
     ST_SetSRID(ST_MakePoint(:lng, :lat), 4326), :weather)
    RETURNING id
    """
    
    result = await db.execute(query, {
        "field_id": reading.field_id,
        "user_id": current_user.id,
        "moisture": reading.moisture_percent,
        "temp": reading.temperature_celsius,
        "ph": reading.ph_level,
        "n": reading.nitrogen_mg_kg,
        "p": reading.phosphorus_mg_kg,
        "k": reading.potassium_mg_kg,
        "notes": reading.notes,
        "lng": reading.gps_longitude,
        "lat": reading.gps_latitude,
        "weather": reading.weather_conditions
    })
    await db.commit()
    
    reading_id = str(result.scalar())
    
    # Publish event for analytics service
    await publish_event("soil_reading_created", {
        "reading_id": reading_id,
        "field_id": reading.field_id,
        "moisture": reading.moisture_percent,
        "timestamp": datetime.utcnow().isoformat()
    })
    
    return {"id": reading_id, "status": "recorded"}

@app.get("/soil-readings/field/{field_id}")
async def get_field_soil_history(
    field_id: str,
    start_date: Optional[date] = None,
    end_date: Optional[date] = None,
    db: AsyncSession = Depends(get_db)
):
    """
    Get historical soil readings for a field
    """
    query = """
    SELECT 
        id, reading_date, moisture_percent, temperature_celsius, ph_level,
        nitrogen_mg_kg, phosphorus_mg_kg, potassium_mg_kg, notes,
        ST_X(gps_location) as longitude, ST_Y(gps_location) as latitude,
        weather_conditions
    FROM manual_soil_readings
    WHERE field_id = :field_id
    """
    params = {"field_id": field_id}
    
    if start_date:
        query += " AND reading_date >= :start_date"
        params["start_date"] = start_date
    if end_date:
        query += " AND reading_date <= :end_date"
        params["end_date"] = end_date
    
    query += " ORDER BY reading_date DESC"
    
    result = await db.execute(query, params)
    readings = result.mappings().all()
    
    return {"readings": [dict(r) for r in readings]}

    Get upcoming irrigation schedules for a farm
    """

    SELECT i.*, f.name as field_name
    FROM irrigation_schedules i
    JOIN fields f ON i.field_id = f.id
    WHERE f.farm_id = :farm_id
    AND i.scheduled_date BETWEEN NOW() AND NOW() + INTERVAL ':days days'

    ORDER BY i.scheduled_date
    """
    
    result = await db.execute(query, {"farm_id": farm_id, "days": days})
    schedules = result.mappings().all()
    
    return {"schedules": [dict(s) for s in schedules]}

from fastapi import FastAPI, Depends
from sqlalchemy.ext.asyncio import AsyncSession
from geoalchemy2.functions import ST_Contains, ST_Distance, ST_AsGeoJSON
from pydantic import BaseModel
import json

app = FastAPI(title="Field Management Service")

# Pydantic models
class FarmCreate(BaseModel):
    name: str
    boundary: dict  # GeoJSON
    total_area_hectares: float

class FieldResponse(BaseModel):
    id: str
    name: str
    boundary: dict
    current_crop: str
    soil_type: str

# Endpoints
@app.post("/farms", response_model=dict)
async def create_farm(farm: FarmCreate, db: AsyncSession = Depends(get_db)):
    """Create farm with geographic boundary"""
    query = """
    INSERT INTO farms (name, boundary, total_area_hectares)
    VALUES (:name, ST_GeomFromGeoJSON(:boundary), :area)
    RETURNING id
    """
    result = await db.execute(query, {
        "name": farm.name,
        "boundary": json.dumps(farm.boundary),
        "area": farm.total_area_hectares
    })
    await db.commit()
    return {"id": str(result.scalar())}

@app.get("/fields/nearby")
async def get_nearby_fields(
    lat: float, 
    lng: float, 
    radius_meters: float = 5000,
    db: AsyncSession = Depends(get_db)
):
    """Find fields within radius using PostGIS"""
    query = """
    SELECT f.id, f.name, ST_AsGeoJSON(f.boundary) as boundary, 
           c.name as crop_name, f.soil_type
    FROM fields f
    LEFT JOIN crop_cycles c ON f.current_crop_id = c.id
    WHERE ST_DWithin(
        f.boundary::geography,
        ST_SetSRID(ST_MakePoint(:lng, :lat), 4326)::geography,
        :radius
    )
    """
    result = await db.execute(query, {"lat": lat, "lng": lng, "radius": radius_meters})
    fields = result.mappings().all()
    return {"fields": [dict(f) for f in fields]}

@app.get("/fields/{field_id}/dashboard")
async def get_field_dashboard(field_id: str, db: AsyncSession = Depends(get_db)):
    """
    Aggregate field data: boundaries, latest soil reading, upcoming irrigation
    """
    # Get field details
    field_query = """
    SELECT f.*, ST_AsGeoJSON(f.boundary) as boundary_geojson,
           c.crop_type, c.planting_date, c.expected_harvest
    FROM fields f
    LEFT JOIN crop_cycles c ON f.current_crop_id = c.id
    WHERE f.id = :field_id
    """
    field = await db.execute(field_query, {"field_id": field_id})
    field_data = field.mappings().first()
    
    # Get latest soil reading
    soil_query = """
    SELECT * FROM manual_soil_readings
    WHERE field_id = :field_id
    ORDER BY reading_date DESC
    LIMIT 1
    """
    soil = await db.execute(soil_query, {"field_id": field_id})
    latest_soil = soil.mappings().first()
    
    # Get upcoming irrigation
    irrigation_query = """
    SELECT * FROM irrigation_schedules
    WHERE field_id = :field_id AND status = 'scheduled'
    ORDER BY scheduled_date
    LIMIT 1
    """
    irrigation = await db.execute(irrigation_query, {"field_id": field_id})
    next_irrigation = irrigation.mappings().first()
    
    return {
        "field": dict(field_data),
        "latest_soil_reading": dict(latest_soil) if latest_soil else None,
        "next_irrigation": dict(next_irrigation) if next_irrigation else None
    }

```python
# ai_service/main.py
from fastapi import FastAPI, File, UploadFile, BackgroundTasks
from motor.motor_asyncio import AsyncIOMotorClient
import tensorflow as tf
from PIL import Image
import io
import hashlib
from datetime import datetime

app = FastAPI(title="AI Diagnosis Service")

# MongoDB async client
client = AsyncIOMotorClient("mongodb://mongodb:27017")
db = client.agri_db

# Load ML model
model = tf.keras.models.load_model("models/pest_classifier_v2.h5")

@app.post("/diagnose")
async def diagnose_image(
    file: UploadFile = File(...),
    farm_id: str = None,
    field_id: str = None,
    background_tasks: BackgroundTasks = None
):
    """
    Async image processing with background ML inference
    """
    # Read and hash image
    contents = await file.read()
    image_hash = hashlib.sha256(contents).hexdigest()
    
    # Check cache first
    cached = await db.diagnoses.find_one({"image_hash": image_hash})
    if cached:
        return {"diagnosis_id": str(cached["_id"]), "cached": True}
    
    # Store metadata immediately
    doc = {
        "image_hash": image_hash,
        "farm_id": farm_id,
        "field_id": field_id,
        "status": "processing",
        "created_at": datetime.utcnow()
    }
    result = await db.diagnoses.insert_one(doc)
    diagnosis_id = result.inserted_id
    
    # Trigger background ML processing
    background_tasks.add_task(
        process_image_ml, 
        contents, 
        diagnosis_id,
        image_hash,
        farm_id
    )
    
    return {"diagnosis_id": str(diagnosis_id), "status": "processing"}

async def process_image_ml(image_bytes: bytes, diagnosis_id, image_hash, farm_id):
    """Background task: ML inference and result storage"""
    # Preprocess
    image = Image.open(io.BytesIO(image_bytes))
    image = image.resize((224, 224))
    img_array = tf.keras.preprocessing.image.img_to_array(image)
    img_array = tf.expand_dims(img_array, 0)
    
    # Inference
    predictions = model.predict(img_array)
    class_idx = tf.argmax(predictions[0]).numpy()
    confidence = float(tf.reduce_max(predictions[0]).numpy())
    
    pest_name = PEST_CLASS_NAMES[class_idx]
    
    # Update MongoDB with results
    await db.diagnoses.update_one(
        {"_id": diagnosis_id},
        {"$set": {
            "status": "completed",
            "diagnosis.pest_identified": pest_name,
            "diagnosis.confidence": confidence,
            "diagnosis.affected_area_percent": float(predictions[0][class_idx] * 100),
            "updated_at": datetime.utcnow()
        }}
    )
    
    # Publish event for notification service
    await publish_event("diagnosis_completed", {
        "diagnosis_id": str(diagnosis_id),
        "farm_id": farm_id,
        "pest_identified": pest_name,
        "confidence": confidence
    })
```

## Appendix B: Data Entry Workflows

### Manual Soil Reading Workflow
1. Farmer visits field with tablet/mobile device
2. Takes soil sample and measures (or sends to lab)
3. Enters data via mobile app: moisture, pH, NPK values
4. System stores in PostgreSQL with GPS coordinates
5. Analytics service calculates trends and recommendations
6. Irrigation schedule suggested based on manual thresholds

### Irrigation Scheduling Workflow
1. System checks latest manual soil reading
2. If moisture < 30%, suggests irrigation
3. Farmer reviews weather forecast (integrated API)
4. Farmer schedules irrigation via app
5. System logs scheduled event
6. Farmer confirms completion after irrigation

### AI Diagnosis Workflow
1. Farmer spots potential pest/disease in field
2. Takes photo with smartphone
3. Uploads to AI service via app
4. Background ML processing identifies pest
5. Treatment recommendations provided
6. Farmer validates accuracy (feedback loop)
```

This is the complete simplified AgriManagement System documentation with IoT functionality removed, focusing on manual data entry, PostgreSQL/PostGIS for relational and spatial data, and MongoDB for AI and forum content.
